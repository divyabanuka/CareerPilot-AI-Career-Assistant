# CodeAlpha Language Translation Tool

An AI-powered language translation tool built with Python, Gradio, and Deep Translator.

## Features

- Translate text between multiple languages
- Simple and user-friendly interface
- Supports English, Hindi, Telugu, Tamil, Kannada, Malayalam, Spanish, French, German, Japanese, Chinese, and Arabic
- Fast translation using an online translation service

## Technologies Used

- Python
- Gradio
- Deep Translator
- Google Translate

## How to Run

1. Open the Google Colab notebook.
2. Install the required libraries.
3. Run all the cells.
4. Use the Gradio interface to translate text.
